# Typing Pet · macOS 个人使用版

随打字动作切换姿势的桌面宠物。此版本根据 Typing Pet 的公开功能说明独立实现，非原作者发布的官方 Mac 版。默认三张基础状态图由本项目使用者提供，权利归相应权利人；另保留原版本的两张模式图片。

## 安装与第一次启动

1. 解压 `typingpet-mac-v1.0.0-universal.zip`，将 `Typing Pet.app` 放入“应用程序”文件夹，再打开。
2. 在“系统设置 → 隐私与安全性 → 输入监控”允许 Typing Pet。系统可能要求退出并重新打开应用，授权后请照提示重启。
3. 在其他应用中打字，宠物会交替抬手并轻微弹跳。系统安全输入启用时（例如密码输入期间），全局输入事件可能暂时不可用。

本地构建采用临时签名（ad-hoc），没有 Developer ID 签名或 Apple 公证。若系统阻止首次打开，可在“系统设置 → 隐私与安全性”按系统提供的提示打开。

2026-10-25 的默认图片替换沿用既有 v1.0.0。新安装会显示新的三张基础状态图，应用图标由新的默认图生成。替换现有应用不会清除自定义图片或设置；在“图片与按键”中恢复默认可显示新的内置图，仍引用内置基础图的预设也会使用新图。

## 常用操作

- 拖动宠物改变位置；右键宠物或点击菜单栏图标打开菜单和设置。
- 在设置里调整大小、弹跳、置顶、透明度，或替换基础／左手／右手图片。
- “锁定位置”会让鼠标穿过宠物。锁定后，请通过菜单栏图标解锁。
- 可以绑定特定按键、组合键或鼠标按钮的专用图片，并保存预设、显示额外宠物。
- 若要登录时自动启动，请先把应用放到“应用程序”文件夹，再启用该设置。macOS 可能要求在“系统设置 → 通用 → 登录项”中允许。
- 从菜单栏菜单退出应用。

支持 macOS 13 或更新版本。默认构建会生成 Apple 芯片与 Intel 通用应用；请以构建末尾的 `Architectures` 输出为准。使用 `TYPINGPET_NATIVE_ONLY=1` 构建时只包含当前机器架构。

## 文件、隐私与兼容范围

应用离线运行，不保存输入的文字或按键历史，也不发送输入数据。设置、复制的自定义图片和错误记录保存在：

```
~/Library/Application Support/TypingPetMac/
```

预设文件使用本版自己的格式，不兼容 Windows 版预设包或配置。Mac 的 Command／Option 等按键按 macOS 规则处理。全屏独占或受系统保护的界面可能限制桌面叠加显示与输入监听。

卸载前关闭登录时自动启动并退出应用，再移除 `Typing Pet.app`。如需同时删除设置与图片，可移除上述数据文件夹。

## 从源码构建

安装 Xcode Command Line Tools 后，在本文件所在目录执行：

```sh
./build.sh
```

生成 `dist/Typing Pet.app` 和 `dist/TypingPet-macOS.zip`。构建脚本校验目标架构与本地代码签名；这些校验不等于完成了系统权限与桌面交互的人工测试。
